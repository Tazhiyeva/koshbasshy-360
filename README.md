# Топ тесттері

«Көшбасшылық негіздері» және «Жалпы психология» пәндері бойынша топқа арналған тесттер беті.

Студент оқытушыдан алған жеке кодымен бір рет кіріп, тізімнен тестті таңдайды:

- **Көшбасшы 360** — өзін және топтастарын 6 құзырет бойынша бағалап, топтың көшбасшысын анықтау.
- **Ес: не түсіндім?** — «Ес» сайтының әр тарауы бойынша не түсінгенін тексеру (баға қойылмайды).

Жауаптар оқытушының Google кестелерінде сақталады.
