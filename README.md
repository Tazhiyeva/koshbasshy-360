# Көшбасшы 360

«Көшбасшылық негіздері» пәні бойынша топтық 360° көшбасшылық бағалау беті.

Қатысушы оқытушыдан алған жеке кодымен кіреді. Ол өзін және топтастарын 6 құзырет (12 тұжырым) бойынша 1–5 шкаласымен бағалайды, соңында топтың көшбасшысын таңдайды. Жауаптар оқытушының Google кестесінде сақталады.
